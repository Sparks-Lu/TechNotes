## AI Token 行业 vs 电力行业：产业链类比与未来市场格局推演

**这个框架下，行业格局会更清晰：**

发电机组制造端会走向寡头格局，就像全球大型发电设备制造商就那么几家（GE、Siemens、三菱、东方电气、上海电气）。模型研发也会收敛到少数几家——因为训练前沿模型的资本门槛越来越高，小玩家会逐渐退出"造机组"的赛道，转而购买大厂的模型授权。

发电（推理）环节会出现明显的成本曲线分化。拥有自研芯片的云厂商（Google TPU、AWS Trainium、华为昇腾）相当于"自备电厂"，成本更低；纯外购 GPU 的厂商成本更高。长期看推理价格会持续下降，但拥有垂直整合能力的云厂商能维持更好的毛利。

电力公司（云厂商）之间的竞争核心会从"谁的模型好"转向"谁的度电成本低"。这就是为什么刚才那张图里 H100 租金相对坚挺——目前"发电设备"（GPU）仍然稀缺，但随着国产替代和专用推理芯片成熟，这个环节也会走向价格战。

**最值得关注的变量是"分布式发电"的可能性。** 电力行业经历过从集中式大电厂到分布式光伏的转变。AI 推理也可能出现类似趋势——端侧模型（手机、PC 上跑的小模型）就是"屋顶光伏"，用户本地推理、零边际成本、不经过云厂商。如果端侧推理能力持续提升，云厂商的"售电量"增长可能会低于预期，这也是 Token 支出指数暴跌的一个潜在解释。



**未来市场格局的推演：**

如果沿着电力行业的路径走，大概率会经历三个阶段。需要明确的是：大模型研发企业（OpenAI、Google、DeepSeek）类比的是发电机组制造商（GE、Siemens、东方电气），而不是发电厂；云厂商（阿里云、AWS、火山引擎）才是类比发电厂/电力公司，负责"发电"（推理）和"卖电"（卖 Token）。

第一阶段是当前的"跑马圈地"期。在"设备制造端"，大模型厂商争夺技术领先地位和开发者生态，类似发电机组制造商争夺技术标准和订单；在"发电端"，云厂商低价甚至免费输出 Token 抢用户，类似电力行业早期"各自建电网"抢地盘。

第二阶段是"标准化与互联互通"。模型能力趋于同质化，"发电机组"的差异化缩小；Token 定价趋于透明和标准化，出现类似"国家电网"的统一调度平台（模型路由/网关层），用户不需要关心底层用的是哪个模型、哪家云厂商。

第三阶段是"基础设施化"。Token 成为像水电一样的通用生产要素，按量计费、即开即用。利润主要集中在"设备制造"（前沿模型研发，技术壁垒最高）和"用电端"（应用层创新）两端，中间的"发电"（推理）和"输配"（路由）环节变成薄利的通道业务——就像电力行业中，发电和输配电的利润率远低于设备制造商和用电端的创新企业。

**但 AI Token 行业和电力有一个本质区别：** 电力的需求是相对稳定的（照明、动力、制冷），而 AI 的需求弹性极大——价格下降 10 倍可能带来 100 倍的需求增长（Jevons 悖论）。这意味着 Token 行业即使单价趋近于零，总市场规模仍可能持续扩张。从刚才那张图来看，Token 支出指数虽然暴跌，但如果同期 Token 消耗量在大幅增长，那说明行业正在经历"量增价跌"的基础设施化早期阶段。

**对投资的启示：** 如果这个判断成立，那么当前公募基金极度拥挤的电子/半导体板块（97% 分位）可能面临分化——上游 GPU 芯片的超额收益会逐步收窄，而真正能跑出来的是下游应用层（"用电端"的创新）和模型路由/调度层（"配电端"的平台）。这也和北向资金 Q2 大幅买入电力设备（+887 亿）但公募在减仓（-5.4pp）的分歧吻合——外资可能更早看到了"AI 电力化"的趋势。

| 阶段  | 环节定位         | 电力行业                        | AI Token 行业                          |

### 三、核心洞察

**1. Jevons 悖论效应**

- Token 价格每下降 10 倍，需求增长 100 倍
- 价格下降不会压缩市场，反而指数级扩大市场
- 与电力行业历史高度一致：电价下降 → 电气化革命

**2. 基础设施化路径**

- Token 将从"奢侈品"变为"日用品"
- 如同电力从工业专属走向千家万户
- AI 应用将渗透到所有行业和场景

**3. 价值链重构**

- 上游（模型研发）：高壁垒、高投入、赢家通吃
- 中游（推理服务）：规模化运营、成本竞争、马太效应
- 中游（路由分发）：连接价值、生态位关键
- 下游（应用场景）：百花齐放、长尾市场巨大

### 四、三阶段演进推演

**第一阶段：爆发期（2024-2027）**

- 大模型厂商混战，争夺用户和开发者
- Token 价格快速下降，应用场景快速扩张
- 云厂商大规模建设推理基础设施
- 类比：电力行业早期，各家建电厂抢市场

**第二阶段：整合期（2027-2030）**

- 市场格局初步稳定，头部效应显现
- 推理成本接近边际成本，价格战趋缓
- 路由/网关层价值凸显，生态位分化
- 类比：电力行业整合，形成几大电网公司

**第三阶段：成熟期（2030+）**

- Token 成为真正的基础设施，按需取用
- 市场进入稳定增长，类似公用事业
- 创新焦点转向下游应用和垂直场景
- 类比：电力行业成熟期，稳定运营+新能源转型
