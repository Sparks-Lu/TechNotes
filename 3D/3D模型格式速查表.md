## 3D 模型格式速查表

面向室内 / 展厅 / 资产库 / ExpoVR 工作流整理。列含义：**材质** = 能否带纹理或 PBR 材质；**动画** = 能否带骨骼 / 关键帧；**Web/VR** = 能否直接进网页 / 实时引擎（★ = 最适合，需导出 = 不能直接用）。

### 一、原生工程格式（各软件的源文件，都要导出才能给引擎/Web 用）

| 格式 | 材质 | 动画 | 用什么打开 | Web/VR | 定位 |
|---|---|---|---|---|---|
| `.max` | 有（节点复杂） | 有 | 仅 3ds Max | 需导出 | 国内室内/展厅效果图主流 |
| `.skp` | 简单 | 弱 | SketchUp / Viewer | 需导出 | 方案 / 体块快速建模 |
| `.blend` | 有（PBR 节点） | 有 | Blender（开源） | 需导出 | 通用 / 独立设计师 |
| `.ma` / `.mb` | 有 | 强 | Maya | 需导出 | 影视 / 动画 / 游戏角色 |
| `.c4d` | 有 | 有 | Cinema 4D | 需导出 | 电商 / 栏目包装 / 动效 |
| `.3dm` | 简单 | 弱 | Rhino（+Grasshopper） | 需导出 | 参数化 / 异形 / 幕墙 / 珠宝 |
| `.sldprt` / `.step` / `.iges` | 仅几何（step 可带色） | 无 | SolidWorks / UG / FreeCAD | 否 | 机械 / 工业结构 |
| `.dwg` / `.dxf` | 无 | 无 | AutoCAD | 否 | 平面底图 / 尺寸图 |

### 二、跨软件交换格式（导来导去靠这些，丢材质最少）

| 格式 | 材质 | 动画 | 用什么打开 | Web/VR | 定位 |
|---|---|---|---|---|---|
| `.fbx` | 有（可嵌入） | 强（骨骼/动画） | Max / Blender / Maya / Unity | 需再转 | 跨软件首选 |
| `.obj`（+`.mtl`） | 有（靠 mtl + 贴图） | 无 | 几乎所有软件 | 否 | 静态模型通用 |
| `.dae` | 有 | 有 | Blender / 游戏引擎 | 一般 | 开源交换（Collada） |
| `.3ds` | 简单 | 弱 | 多数软件 | 否 | 老格式，渐淘汰 |
| `.abc`（Alembic） | 无（时序几何） | 几何动画 / 形变 | Maya / Blender | 否 | 影视大缓存 |
| `.stl` | 无 | 无 | 切片软件 / Blender | 否 | 3D 打印，只有网格 |
| `.3mf` | 有（颜色） | 无 | 切片 / Bambu Studio | 否 | 3D 打印 |

### 三、实时 / Web / VR / AR 格式（能直接上线或预览）

| 格式 | 材质 | 动画 | 用什么打开 | Web/VR | 定位 |
|---|---|---|---|---|---|
| `.glb` / `.gltf` | 有（PBR） | 有（骨骼/关键帧） | three.js / Babylon / Blender | ★ 最适合 | 交付主格式，单文件 |
| `.usdz` | 有（PBR） | 有限 | iOS Safari / AR Quick Look | AR 预览 | iPhone AR / 苹果生态 |
| `.usd` / `.usdc` | 有 | 有 | Blender / USD 工具 | 增长中 | Pixar / OpenUSD 新趋势 |

### 选型口诀（结合 ExpoVR 展厅链路）

拿到的源文件若是 `.max` / `.skp`，用 **`.fbx`** 作中间交换最省心（材质、骨骼都能带）；对外交付、进 Web/VR 一律最终落成 **`.glb`**（PBR + 动画、单文件、引擎通吃）；需要 iPhone AR 预览时再补一份 **`.usdz`**。

`.max` → `.glb` 的两条常用路径：
- 装了 Babylon.js 插件：3ds Max 菜单 `Babylon → Babylon File Exporter`，`Output format = glb` 直接出。
- 不装插件：3ds Max `Export → FBX（嵌入贴图）` → Blender `Import → FBX` → `Export → glTF 2.0 (.glb)`。

### 备注

`.max` / `.skp` 等原生格式为专有格式，没有可靠的免费独立查看器能直接打开，需对应软件；跨环境务必先转通用/实时格式。第三方素材站（如 3D 溜溜网）下载的模型多为 `.max`，且**默认不含商用授权**，商用前需按用途单独购买授权并留存授权书。
