> 调研时间：2026-11-19
> 范围：把户型图（扫描件、PDF、营销渲染图、DWG/SVG 矢量图纸、手机拍照）与真实空间（点云/视频）转成**结构化空间数据**——房间多边形与语义、墙/门/窗/楼梯符号、家具、文字与尺寸标注，并可下接到 CAD/BIM/IFC/3D。

## 0. 结论速览

1. **范式已从"像素分割"转向"矢量输出"。** FP-Comp（WACV 2023）把多源统一成 panoptic 基准（PQ/SQ/RQ），但像素掩码"好看却不可编辑"；2024–2026 的重心是 RoomFormer（端到端带序多边形）、PolyRoom、Raster2Seq（seq2seq 多边形序列，SIGGRAPH/TOG 2025）。

2. **"检测 vs 发射"是 2026 年最值得记住的一条工程结论。** 独立预印本（fpvec-lab，2026-08）在同一训练网络上比较两种 readout：在真实扫描件（CubiCasa5K）上检测式全面更优——opening F1 从 0.25 提到 0.64（**2.6 倍，且无需重训**），wall F1 提升 2.7–5.1；而在干净矢量渲染图（Structured3D 类）上自回归序列解码反超 5–8 点；两族输出融合再涨 wall F1 约 7。**规则：大张真实扫描件用检测，小张/干净渲染用发射。**

3. **CAD/DWG 不能套用栅格模型。** FloorPlanCAD 定义了 primitive 级 symbol spotting（30 类），Baseline mAP≈0.45 / PQ 0.561 / 加权 F1 0.798；后续 CADTransformer/GAT-CADNet/SymPoint/VectorGraphNet 在 2025–2026 把加权 F1 推到 88–89。这一支的技术难点是"线元即对象"，而非像素分类。

4. **"扫描即识别"已成为商业落地主路径。** SpatialLM（NeurIPS 2025，群核）从点云/单目视频直接输出墙/门/窗与带朝向的物体框，训练集 12,328 场景 / 54,778 房间；国内产品端如视庞加莱 R1 宣称"4 分钟扫 100㎡、云端 15 分钟出 DXF"。**注意：SpatialLM 权重为 cc-by-nc-4.0，不可商用。**

5. **通用 VLM 直接读图给坐标仍不可靠。** FloorplanQA（2025–2026 v4）与 ArchPlanVQA（ASCE JCCE 2026-06）两个基准结论一致：前沿模型能答对浅层问题，但**常违反物理约束、空间不一致**；矢量化预印本的 zero-shot VLM 对照也是"拓扑大致对、坐标粗糙"。生产上仍需专用检测器 + 约束解码/求解。

6. **数据集许可是本领域最大的雷区。** CubiCasa5K、FloorPlanCAD 均为 **CC BY-NC 4.0（禁商用）**，RPLAN **禁止再分发且衍生数据亦不可发布**；明确可商用的矢量基准目前只有 **ResPlan / ResPlan-FP（CC BY 4.0，代码 MIT）**。用 NC 数据训练出来的模型上线，商业风险由己承担。

7. **商业产品的精度表述普遍没有量纲。** 厂商"识别率 95%+""误差 ≤3mm""15 分钟出 CAD""500 页 3 分钟、误差 <1%"均未说明任务、数据集、指标定义与房型分布，与论文里 corner/angle/room-level F1 不是同一量纲，不能并列引用。

8. **市场结构稳定且需求刚性。** 中国侧是"量房→户型→设计→报价"链路（存量房翻新占比 2025 首破 50%）；海外侧是 SaaS 订阅 + 按次服务（Polycam $34/月或 $400/年、CubiCasa 单次约 $15–35 但口径冲突、Matterport 平面/CAD 导出按次加费），纯"识别→IFC 一步到位"的产品至今没有出现。

## 2. 概念边界：识别、解析、矢量化、结构化建模是四件事

| 层次 | 交付物 | 典型验收 | 谁在做 |
|---|---|---|---|
| **识别**（detection/classification） | 类别框/掩码 | mAP、PQ | 学术基线、标注平台 |
| **解析**（parsing） | 符号 + 关系（墙-门-房间拓扑） | GED、关系召回 | FP-Comp、CAD symbol spotting |
| **矢量化**（vectorization） | 顶点序列多边形、带图层 DXF/SVG | corner/angle F1、LiCS、edit-cost、watertight | RoomFormer、Raster2Seq、fpvec |
| **结构化建模** | 3D 墙体/门窗/家具、IFC/BIM、可漫游 | 尺寸误差、可编辑性、返工工时 | 如视、Matterport、广联达、Revit 插件链 |

**关键提醒**：厂商说"识别率 90%+"时，必须追问是哪一层的指标。像素掩码 PQ 0.6 与"出图可用"之间，往往还隔着一次人工描图。

## 3. 技术进展

### 3.1 栅格全景解析的成熟与天花板

FP-Comp（WACV 2023）把 CVC-FP、FloorPlanCAD、RPLAN、SESYD、BRIDGE 统一到 panoptic 框架（房间 + 墙/开口 + 家具），指标 PQ/SQ/RQ；FPNet 用多分支注意力把"房间语义 + 线元素"放进一个网络。这条线的优点是**训练与评测标准化**，缺点同样明确：输出是掩码，工程上必须再做一次 raster-to-vector，而**弧形墙、非正交墙在这一步几乎必坏**；房间中心式表示也无法恢复"不构成房间边界的悬空墙/外墙"（有工作报告该类召回仅 0.30 vs 0.66）。

### 3.2 端到端矢量化：从分割+后处理到多边形序列

- **RoomFormer（CVPR 2023，MIT）**：双层级 query 直接输出带序顶点，19 类联合预测房间/门/窗，是"分割后处理"路线被替代的起点。落地门槛不在模型而在 CUDA 扩展编译与 Structured3D/SceneCAD 数据预处理。
- **PolyRoom（2024）**：把表示重心从角点挪到房间中心，改善闭合性与重叠。
- **Raster2Seq（SIGGRAPH/TOG 2025，MIT）**：把 raster→vector 当作**序列到多边形的 seq2seq 生成**（可学习锚点 + 可变形注意力），Structured3D-B 上 Room F1 99.6 / Corner F1 98.3 / Angle F1 92.7（含排列 + 锚点 + FeatFusion 的完整模型），对 in-the-wild 图片泛化最好；作者复现官方 checkpoint 的 room F1 为 0.8854（论文 0.887），复现性尚可。
- 与"生成"侧的接口：户型生成（FMLM/HouseMind）与识别矢量化（Raster2Seq/fpvec）现在共用同一类"离散 token + 约束解码"的表示语言，这是 2026 年该领域最值得注意的收敛趋势。

### 3.3 关键实证：真实扫描件用"检测"，干净图用"发射"

fpvec-lab（2026-08 预印本，独立作者，MIT）用同一训练网络对比两种 readout：

| 场景 | 更优方案 | 差距 |
|---|---|---|
| 真实扫描件（CubiCasa5K） | **检测式** | wall F1 +2.7@0.05、+5.1@0.015；**opening F1 0.25→0.64（2.6×，无需重训）** |
| 干净矢量渲染图 | **发射式（自回归序列）** | 反超 5–8 点 |
| 两者融合 | 融合 | wall F1 再 +7 |

它还提出了 **edit-cost（编辑成本）指标**——按人工返工量而非几何 IoU 打分，这比传统指标更贴近产品验收。该数据集 **ResPlan-FP（CC BY 4.0）** 是目前唯一明确可商用的矢量户型基准。

> 可信度：非同行评议预印本，edit-cost 权重为人工设定，ResPlan-FP 存在近重复样本；但"检测 vs 发射"这一对比方向与产品端经验一致，值得作为内部选型依据，不能作为绝对优劣结论。

### 3.4 CAD/DWG 矢量图纸是另一个问题域

FloorPlanCAD（ICCV 2021）把任务定义为 primitive 级 symbol spotting（30 类，28 thing + 2 stuff），baseline mAP≈0.45、PQ 0.561、加权 F1 0.798；PolyFloorPlan（CVPR 2023）提出线-胞图表示与 **LiCS** 指标；2025–2026 的 SymPoint（加权 F1 86.8）与 VectorGraphNet（ASCE，89.0）把 CAD 符号识别继续往前推。

要点：

1. 输入已是矢量时，**不要**栅格化再分割——那会把图层/块/线型等强先验丢掉。
2. 这一支几乎所有公开数据都带 **NC 限制**，企业要做自有 DWG 解析基本只能自采自标。
3. FloorPlanCAD 项目已停更（2022/2023），后续代码许可多需逐个核。

### 3.5 点云→结构化户型：扫描即识别

**SpatialLM（NeurIPS 2025，群核）**：输入 3D 点云（可来自单目视频、RGBD、LiDAR），用一个 LLM 直接输出墙/门/窗与带朝向的家具框；训练集 SpatialLM-Dataset 12,328 场景 / 54,778 房间，另附 107 测试集。这一支的商用约束是**权重 cc-by-nc-4.0**，repo 许可证为 NOASSERTION。

产品侧对应变体：如视（P4/R1 点云 + CAD 直出 + Jetson 边缘推理）、Matterport（Pro3 LiDAR + Cortex 自动平面）、Polycam（iPhone Space Mode）、MagicPlan（AR/LiDAR）、知户型（LiDAR + 蓝牙测距）。这条线已经把"识别"从读图挪到了读空间，**图纸识别正在变成其下游环节**。

### 3.6 VLM/LLM 读图：能力真实存在，坐标仍然不可信

- **FloorplanQA（arXiv 2507.07644，v4 2026-05-25）**：给 LLM 结构化布局（JSON/XML），测测距、可见性、寻路、放置——前沿模型能答对浅问题，但**常违反物理约束、前后不一致**。
- **ArchPlanVQA（ASCE J. Comput. Civ. Eng. 40(5)，2026-06）**：专测 VLM 读 CAD 建筑平面图。
- **SpatialThinker（arXiv 2511.07403）**：场景图 + 密集 RL 奖励来补空间推理。
- **HouseMind（CVPR 2026）**：用 VQ-VAE 把房间 token 化后，理解任务房间匹配 99.8%、定位 96.9%、面积误差 0.549 m²、2–3 秒——说明"**先把图变成结构化 token，再交给语言模型**"目前比直接让 VLM 看像素可靠得多。

工程含义：VLM 适合做**需求理解、结果解释、一致性校验**（"这两间卧室是否共用承重墙"），不适合做**坐标生产**。

## 4. 精度现实与失败模式

**真实输入下的量级（第三方汇总，单源、疑为厂商 SEO，仅作区间参考）**：干净 300DPI 扫描件墙元素级精度 90–96%、门窗 85–93%；退化/红笔标注的翻新房降至 70–85%，重标注 <70%；手机斜拍比平扫再降 5–15%；复印缩图带来 1–3% 尺度误差且**无参考尺寸时不可无偏恢复绝对尺度**。

**已被论文与工程文共同确认的失败模式：**

1. **非正交与弧形墙**——依赖 Manhattan/正交假设的方法在此类房型上系统性失效；Raster2Seq/PolyRoom 针对性缓解；fpvec 用 TopN 弧参数化处理（S4 S11）。
2. **悬空墙/外墙**——room-centric 表示无法恢复"不构成房间边界"的构件（召回 0.30 vs 0.66）。
3. **重叠/开放边界房间**——客厅餐厅无隔断时多边形合并歧义。
4. **中文标注与符号习惯差异**——公开模型几乎全在英文/符号数据集训练，`阳台/玄关/强弱电箱/飘窗` 一类语义与图库缺失。
5. **有无比例尺**——绝对尺度必须锚定至少一个已知尺寸或激光测距，否则只能给相对值。
6. **图纸噪声**——红笔修改、图签表、水印、多楼层叠图、扫描倾斜。

## 5. 商用产品与服务市场

**中国**：识别能力几乎从不单独卖，而是嵌在链路里——

- 量房端：如视（硬件 + CAD 直出 + NVIDIA Jetson 边缘重建）、知户型（手机 LiDAR + 会员/团队订阅）。
- 设计-生产端：群核/酷家乐（拍照建户型、AI 识别建模、Aholo API，2026H1 AI 新应用收入 3,100 万元、+177%）、三维家（2,800 万+ 户型库匹配 + 拆单）。
- 工程算量端：广联达（识图算量、云尺图片转 CAD、数维 BIM）、天正（DWG 语义事实标准）、鹏业/品茗/鲁班/斯维尔/智多星等。
- 需求基本盘：2025 年住宅装饰装修规模突破 5.7 万亿元，存量房装修套数占比首次过半（约 52.3%，机构口径 56–65%），老房翻新需求由 2020 年 582 万户增至 2025 年 1,054 万户（CAGR≈12.6%）；2025 年新开工改造城镇老旧小区 2.71 万个、499 万户、投资 1,332 亿元（住建部口径）。

**海外**：三条清晰分层——

1. **硬件+SaaS**：Matterport（订阅 $9.99–309、Pro3 相机 $3,000–5,500，平面/CAD 导出按次收费；CoStar 收购后与 Zillow/Redfin/MLS 打通）。
2. **移动扫描**：Polycam（Business $34/月或 $400/年，强调"无按次费 + CAD 交付"）、MagicPlan、CubiCasa（单次 $15–35 口径冲突）。
3. **数据/标注 B2B**：CubiCasa 的标注业务（也是 CubiCasa5K 的来源，NC 限制）。

服务单价锚点：全自动 SaaS 约 $0.5–5/张或 $20–500/月；桌面 CAD 插件 $500–2,000/席/年；人工重绘 4–8 小时/套；国内量房人工 200–500 元/套、如视 VR 拍摄约 100–300 元/套（含户型图 + 3D + 全景）。

## 6. 选型与落地建议

| 场景 | 推荐 | 说明 |
|---|---|---|
| 上传真实扫描/PDF 户型图 | 检测式矢量（RoomFormer/自研 + 融合发射式） | 依据 3.3：真实扫描件检测 readout 显著更稳，尤其开口 |
| 营销渲染图/小程序里的"看起来像"的图 | 发射式序列（Raster2Seq 一类） | 干净小图上自回归更强 |
| 企业存量 DWG/施工图 | CAD 矢量符号识别专用线 | 栅格模型直接套用必掉精度 |
| 房产/展馆现场交付 | 点云/扫描产品（如视、Matterport、Polycam）或合作 API | 图纸识别退为下游 |
| 中文家装场景自建 | ResPlan-FP（CC BY 4.0）+ 自采中文标注 | 唯一许可干净的矢量基线数据 |
| 只做"问答/校验/说明" | VLM + 已解析的 JSON 布局 | 不要让 VLM 出坐标 |
| 需要 IFC/BIM 交付 | 矢量 DXF（带图层与真尺度）→ Revit/ArchiCAD/Allplan 二次建模 | 一步到位产品目前不存在 |

**自建服务的资源基线**：矢量化模型推理约需 8–16 GB 显存（SpatialLM/SpatialGen 类建议 ≥16 GB，训练或高分辨率 24 GB+）；分割模型 CPU 可跑但单张从秒级掉到分钟级；服务端要加异步队列与幂等、冷启动预热。人工兜底是常态——**任何"全自动"宣传都应以"多少比例的图需要返工"来验收**。

## 7. 到 CAD/BIM/IFC 的现实路径

1. **矢量化输出带图层与真尺度的 DXF/DWG（或结构化 JSON 顶点）**，再由 CAD/Revit/ArchiCAD/Allplan 二次建模——这是当前唯一稳定路径。fpvec-lab 的 JSON 顶点可直接喂 Dynamo/Revit 脚本；Finch3D 反向（布局→IFC/DXF/RVT）可作对照。
2. 如视、广联达数维支持导出 CAD/BIM/IFC/USD；Matterport 支持 E57、MatterPak、BIM 与示意平面图。
3. **"识别→IFC 一步到位"的产品在 2026 年仍未出现**，主流仍是"AI 出底图 + 人工补齐"。评估采购时，请把"导入 Revit 后需要重画多少"当成第一指标，而不是识别率。

## 9. 诚实边界

1. **厂商自报精度一律未独立验证**：如视"3 mm（计量院报告）/ 15 分钟出 CAD / 5,800 万空间 / 3D 物品召回 95% / 面积误差 <1%"；三维家"识别 95%+ / 30 秒 / ±2 mm / 覆盖 90%+ 小区"；广联达"500 页 3 分钟、误差 <1%"；CubiCasa"95–97% 精度 / 4M+ 平面"；Matterport"看房快 31% / 询盘 +95%"（内部数据）。这些不能作为选型基准。
2. **"识别率超 90%"缺量纲**：未交代任务层级（像素/符号/多边形/可交付）、数据集、指标定义与房型分布，与论文的 corner/angle/room F1 不可并列。
3. **单源数字风险**：archparse.com 系列（墙 90–96%、门窗 85–93%、退化 70–85%、斜拍 −5–15%、$0.5–5/张、ROI $140–480）疑为厂商 SEO，本文仅作区间参考。
4. **预印本未同行评议**：fpvec-lab（检测 vs 发射）为独立作者 2026-08 预印本，edit-cost 权重人工设定、ResPlan-FP 存在近重复；Structured3D 官方 test split 未报，训练数据可能有重叠。
5. **定价冲突**：CubiCasa 各来源 $15 / $22.99+$29.99 / $34.90 / 免费并存且页面长期未更新；其是否被收购、股权归属均未证实。
6. **未核实清单**：PolyFloorPlan（仓库 404）、FP-Comp/FPNet/PolyRoom/CAD 系方法的 repo 许可；"如视 Realsee3D 含 CAD 标注"未见公开学术数据集；名为 S2CS-CAD 的数据集未证实存在（命中的是 2025 的 Drawing2CAD / CAD-VGDrawing）。
7. **本次未做实机复现**：所有指标来自论文/仓库/产品页自述；没有对同一批图做跨方法实测，因此不能给出"在我们数据上谁更强"的结论。
